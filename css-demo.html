🎨 Panduan Visual CSS Layout

Satu file HTML interaktif untuk mempelajari Margin, Padding, Box Model, dan Flexbox.

1. CSS Box Model (Struktur Lapis Elemen)

Setiap elemen HTML dibungkus oleh 4 lapisan kotak berikut:

MARGIN (Jarak Luar)
BORDER (Garis Tepi)
PADDING (Jarak Dalam)
CONTENT (Isi Teks / Elemen)

2. Perbedaan Margin vs Padding

Padding (Jarak Dalam)

Memperbesar ruang antara isi dengan garis tepi elemen itu sendiri.

padding: 2rem;

Margin (Jarak Luar)

Mendorong/memberi jarak antara elemen dengan elemen di sekitarnya.

margin: 1.5rem;

3. Sifat Tampilan (Display)

inline Teks 1 Teks 2

Elemen berdampingan menyamping, lebar menyesuaikan isi konten.

block
Elemen Block (Selalu Mengambil 1 Baris Penuh)

Elemen membuat baris baru dan memenuhi lebar area secara otomatis.
